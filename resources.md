## Software

- [py4DSTEM](https://github.com/py4dstem/py4DSTEM): open source Python code for 4D-STEM analysis, with [tutorial notebooks](https://github.com/py4DSTEM/py4DSTEM_tutorials).
- [quantEM](https://github.com/electronmicroscopy/quantem): machine-learning-powered quantitative electron microscopy. We are looking for contributors.
